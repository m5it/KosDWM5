# Plan: Notices Gadget with HTTP API
## ID: 1784740748.9778647
## Created: 2026-07-22 17:19:08
## Status: in_progress

### Goal:
Create a Notices gadget for KosDWM that allows users to write down notices with date, time, and optional reminders. The gadget will have a full HTTP API for external editing, adding, and viewing notices. The system will include: (1) A NoticesGadget class extending GadgetBase, (2) A data storage system for notices in JSON format, (3) A GUI window for viewing and managing notices, (4) An HTTP API server using Flask for RESTful operations, (5) Reminder functionality using threading, (6) Integration with the existing gadget framework.
